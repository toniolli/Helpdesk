# Helpdesk

Sistema de atendimento e suporte técnico para abrir, acompanhar e distribuir chamados. O projeto inclui controle de acesso, acompanhamento de SLA, auditoria e atualizações em tempo real.

## Frontend

Interface web em React e Vite para solicitantes, técnicos e administradores.

[Ver documentação do frontend](./Helpdesk-Frontend/README.md)

## Backend

API REST em ASP.NET Core 9, com Oracle e SignalR. Pode ser executada localmente ou com Docker.

[Ver documentação do backend](./Helpdesk-Backend/README.md)
